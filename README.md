# 老式调车机工房

一个纯前端窄轨调车 / 编组推演小游戏。轨道穿过仓库与站台，调 0 号机车既能前端牵引，也能以另一端为先导推进或倒拖。

## 已实现的调车规则

- 车辆在轨道节点间逐手移动；同一车列同步换位，车钩间距始终保持。
- 道岔按“直股 / 岔股”开通；任一节车的当前位置或上一手位置仍压着岔喉时，禁止扳岔。
- 推进短车列入岔后反向牵引时，车辆会沿上一手位置逐格退回原轨。
- 完整状态保存每辆车的位置、上一手位置、真实车钩数组、机车朝向、道岔和门。即使机车坐标与朝向相同，身后车列路径不同，可执行的端路也不同。
- 关闭的库门会挡住先导车；该手不产生任何状态变化，因此整列保持原来的接钩间距。
- 可摘钩、点选两端接钩或使用列出的合法接钩操作。从另一端接回会生成新的车序。
- 盘面车序、地磅 / 踏板负载、站台读序和交付判定都从当前真实编组与车位重算。
- 每个场景都附带已校验的有限步调车单，可显示第一手、全单，并支持上一手 / 下一手 / 自动逐手演练。

## 本地运行

```bash
npm install
npm run dev
```

类型检查与生产构建：

```bash
npm run typecheck
npm run build
```

## 领域代码

核心规则与界面解耦，位于 `src/train/`：

- `types.ts`：状态、操作、关卡类型。
- `engine.ts`：移动、道岔锁定、门 / 踏板、摘挂、交付判定和动作枚举。
- `levels.ts`：三个场景：岔线回执、中段换挂、关门停车。
- `plans.ts`：经过引擎回放验证的调车单。
- `solver.ts`：可选的 BFS 求解器；预置调车单保证页面即时可演练。
- `TrainBoard.vue`：SVG 窄轨盘面。
